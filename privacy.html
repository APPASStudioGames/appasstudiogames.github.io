02

Datos que recopilamos

Saps no requiere registro ni cuenta de usuario. No recopilamos nombre, dirección de correo electrónico, número de teléfono ni ningún otro dato personal identificable. Los datos que tratamos son:

a) Identificador de dispositivo anónimo
Generamos un identificador aleatorio único almacenado localmente en tu dispositivo. Este ID no contiene información personal y se usa exclusivamente para asociar tus valoraciones de forma anónima en nuestros servidores. No permite identificarte como persona.

b) Valoraciones
Las puntuaciones que otorgas a los datos curiosos se almacenan localmente y, de forma anónima, en nuestros servidores para mostrar valoraciones globales.

c) Propuestas de datos curiosos
Si envías una propuesta, el texto y la categoría se almacenan en nuestros servidores. No se vinculan a ningún dato personal.

d) Preferencias locales
El tema visual (claro/oscuro), el idioma seleccionado, las fechas desbloqueadas y el estado del Plan Pro se guardan exclusivamente en tu dispositivo mediante almacenamiento local (AsyncStorage). No se envían a ningún servidor.

e) Identificador publicitario (GAID / IDFA)
La aplicación muestra anuncios bonificados a través de Google AdMob. Google puede acceder al identificador publicitario de tu dispositivo (Google Advertising ID en Android, IDFA en iOS) para personalizar los anuncios. Puedes restablecer o desactivar este identificador desde los ajustes de tu dispositivo.

03

Finalidad del tratamiento

Los datos se utilizan exclusivamente para:

• Mostrar el ranking global de datos curiosos más valorados.
• Revisar y publicar propuestas de datos enviadas por usuarios.
• Desbloquear el acceso a contenido mediante anuncios bonificados.
• Validar y restaurar el Plan Pro adquirido.
• Mejorar la experiencia de uso de la aplicación.

No vendemos, cedemos ni compartimos tus datos con terceros con fines comerciales propios.

04

Dado que las valoraciones son completamente anónimas y no vinculadas a ninguna identidad, no es técnicamente posible localizar y eliminar los datos de un usuario específico a partir del identificador de dispositivo.
